# 需求與規則（討論紀錄）

## 資料清理規則
1. 排除模擬場次（Garmin roundType = SIMULATION）。
2. 同一天的前九、後九自動合併成一場。
3. 中油（Taiwan Zhongyou，標準桿 60）為短球場，獨立一類，不混入正規球場趨勢。
4. 未打完的場次：逐洞資料保留，整場總桿不列入趨勢。
5. 待確認：2025-12-05 中油三張計分卡（7、7、9 洞）如何合併。

## 想看的圖表
1. 打壞率時間序列：橫軸時間區間、縱軸打壞率。
2. 洞型成績：Par 3／4／5 的最終成績。
3. 爆桿分析：哪一種洞型最容易爆桿。
4. 距離分層：同一 Par 依洞長分組（例如 300 碼與 350 碼的四桿洞），據此制定不同進攻策略。

## 核心假設（待資料驗證）
高爾夫是打穩而非打遠：穩定的 150 碼勝過忽遠忽近的 170–180 碼。

## 待定義
- 「打壞」門檻（建議：低於該桿當期中位數的 70%）。
- 時間區間切法（按月或按場次滾動）。
- 「爆桿」門檻（超出標準桿 3 桿以上，或 double bogey 以上）。
